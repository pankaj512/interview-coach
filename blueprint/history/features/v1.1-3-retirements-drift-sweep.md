## Goal

Retire the two surfaces that newer work already superseded - the pre-18c
`GET /api/problems/:id` endpoint (superseded by 18c's content endpoint) and
the seven deprecated CLI-harness tool aliases (superseded by the canonical
tool surface) - and close the `project-plan.md` drift-sweep clause. No
behavior change beyond the removed surfaces: unknown tools and unknown
routes keep their existing 4xx shapes.

## In scope

- Extend `GET /api/problems/:id/content` with non-null identity fields
  (`title`, `difficulty`, `topicId`) taken from the catalog row, migrate the
  dashboard off `getProblem()`, then delete `GET /api/problems/:id`.
- Remove the seven deprecated tool aliases end to end: core dispatch cases
  + `DeprecatedToolAlias` / `DEPRECATED_TOOL_ALIASES`, `tool-exec` enum
  narrowing to canonical names, web `ToolName` mirror, forwarder accept
  list, and alias comments in live source.
- Migrate every test that invokes an alias name to its canonical
  equivalent (or delete the alias-specific case).
- Verify the `project-plan.md` §3/§7 drift clause is already satisfied and
  record the no-op.

## Out of scope

- `GET /api/problems` (S5 browser) and all other routes stay untouched.
- Frozen/archival docs (`docs/architecture-frozen.md`,
  `docs/interview-coach-hld-and-implementation-plan.md`,
  `docs/implementation-roadmap.md`, `docs/audit/*`,
  `docs/SESSION_HANDOFF.md`, `blueprint/history/*`) keep their historical
  alias mentions; they are immutable records, not live contracts.
- `blueprint/context/coding-standards.md` drift (open finding F-15) stays
  open; it is ledger work, not this feature.
- No `v1.0`/`v1.1` tagging; that needs a separate push/tag approval.

## Summary

the removals. `GET /api/problems/:id` is deleted; the 18c content endpoint

type mirror, forwarder accept-list); alias calls fail closed with the
existing 400 `VALIDATION_ERROR`. `project-plan.md` section 3/section 7 drift
clause verified already satisfied (no-op, no plan edit). Net -609/+425 lines
across 36 files, pure deletion plus type re-pointing.
