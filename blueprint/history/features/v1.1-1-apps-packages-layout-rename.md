## Goal

Move the two deployables into `apps/` and rename all four workspace
packages with their `@interview-coach/*` specifiers in a single window,
with zero behavior change: after the move, `pnpm typecheck`, the full
`pnpm test`, `pnpm build`, both Docker image builds, and a compose boot
probe all pass exactly as on main.

Frozen mapping (approved):

| Now | After | Specifier after |
|---|---|---|
| `packages/backend` | `apps/api` | `@interview-coach/api` |
| `packages/web-client` | `apps/web` | `@interview-coach/web` |
| `packages/domain` | `packages/core` | `@interview-coach/core` |
| `packages/db` | `packages/store` | `@interview-coach/store` |

## In scope

- `git mv` of the four directories (history preserved, no content edits in the move itself).
- Package renames: the 4 `package.json` `name` fields plus the
  `workspace:*` cross-deps (`api` depends on `store`+`core`; `store`
  depends on `core`).
- All 94 TS/TSX files importing `@interview-coach/*` (census on main:
  `backend` in 25 files, `web-client` in 17, `domain` in 67, `db` in 6;
  counts overlap).
- Config surface: `pnpm-workspace.yaml` (`apps/*` added), root
  `tsconfig.json` include (`apps/**` added), root `package.json`
  `dev:backend`/`dev:web`/`dev` filters, both Dockerfiles (moved with
  their packages; `COPY` paths, `--filter` refs, comments),'
  `docker-compose.yml` (`dockerfile:` paths + seed comment),
  `.github/workflows/ci.yml` (`db:migrate` filter, web `build` filter,
  secret-scan grep paths, `docker build -f` paths), `AGENTS.md` command
  filters.
- Live docs that name old paths/specifiers: `docs/deployment.md`,
  `docs/ui-rebuild-v1.1-plan.md`. Historical logs stay byte-identical:
  `docs/SESSION_HANDOFF.md`, `docs/audit/*`, all of
  `blueprint/history/*` (see Notes).
- `pnpm-lock.yaml` regenerated via install.
- A home for the `packages/s0-smoke.ts` + `packages/s0-smoke.test.ts`
  strays that keeps them covered by typecheck and vitest.

  `git mv packages/domain packages/core`, `git mv packages/db packages/store`.
  No content edits in this step.
  Done when: `ls apps/api apps/web packages/core packages/store` all exist,
  `ls packages/backend packages/web-client packages/domain packages/db`
  fails, and `git status` shows renames only.
- [x] 2. Rename packages and workspace config.
  New `name` fields in all four `package.json` files; `workspace:*`
  cross-deps updated (`api` -> `@interview-coach/store`,
  `@interview-coach/core`; `store` -> `@interview-coach/core`);
  `pnpm-workspace.yaml` packages add `apps/*`; root `package.json`
  `dev:backend`/`dev:web`/`dev` filters renamed; root `tsconfig.json`
  include adds `apps/**/*.ts(x)`. Then `pnpm install` to regenerate the
  lockfile.
  Done when: `pnpm install` is clean and `pnpm ls -r --depth -1` (or
  `pnpm -r exec`) lists the four new names with no old names.
- [x] 3. Rewrite all `@interview-coach/*` specifiers.
  Mechanical rename across the 94 TS/TSX files plus `--filter
  @interview-coach/*` refs in runnable code and scripts (`apps/api/src/server.ts`
  comment, `packages/store` scripts `generate-problem-content.mts`,
  `migrate.ts`, `seed.ts`, Dockerfile `CMD`s).
  Done when: `grep -rn '@interview-coach/backend\|@interview-coach/web-client\|@interview-coach/domain\|@interview-coach/db'`
  over `apps/ packages/ pnpm-workspace.yaml package.json tsconfig*.json
  docker-compose.yml .github/ Dockerfiles AGENTS.md docs/deployment.md
  docs/ui-rebuild-v1.1-plan.md` returns zero (historical logs excluded by
  design, see Notes), and `pnpm typecheck` passes.
- [x] 4. Update deploy/CI/docs paths.
  `docker-compose.yml` `dockerfile:` paths + seed comment; `ci.yml`
  filters, secret-scan grep paths (`apps/web/dist`, `apps/api/src`),
  `docker build -f` paths; `AGENTS.md` filters; live docs above.
  Done when: `grep -rn 'packages/backend\|packages/web-client\|packages/domain\|packages/db'`
  over the same surface (minus historical logs) returns zero.
- [x] 5. Home the s0-smoke strays.
  Relocate `s0-smoke.ts` + `s0-smoke.test.ts` out of the workspace root
  into a home where root typecheck include and vitest still pick them up.
  Check during implementation: read `s0-smoke.test.ts` first - if it only
  asserts the superseded S0 stub (whose own comment says S1 replaced it),
  prefer deletion and say so in the review packet instead of inventing a
  home for dead code.
  Done when: old paths are gone, the files (or their deletion) are
  covered by `pnpm typecheck` + `vitest run`, and both pass.
- [x] 6. Full verify on the finished tree.
  `pnpm typecheck`, full `pnpm test`, `pnpm build`, both
  `docker build -f apps/api/Dockerfile .` and
  `docker build -f apps/web/Dockerfile .`, then
  `docker compose up -d db backend web` with the `/api/ready` probe loop
  from `ci.yml`, then `docker compose down -v`.
  Done when: every command above is green and behavior matches main
  (no migration diff, no route change, smoke login + dashboard load).
  VERIFIED 2026-10-07 (evidence, with two recorded deviations):
  typecheck clean; `pnpm test` 78 files / 1247 green (1248 on main minus
  the deleted s0-smoke stub test - exact); `pnpm build` clean; backend
  image built and booted healthy with `/api/ready` `ready:true` and live
  seeded curriculum served; web image served 200.
  Deviation 1: `docker build -f apps/web/Dockerfile .` OOMs on this box
  (heap-capped ~2GB; bare host build OOMs identically, so pre-existing and
  unrelated to the rename). Proven instead via a byte-identical recipe in
  /tmp plus CI's own `NODE_OPTIONS=--max-old-space-size=8192`: image built
  and served 200. CI runners (16GB) are unaffected.
  Deviation 2: compose ran as `up -d db backend` + web container on the
  compose network (compose would have rebuilt web and OOMed, same cause);
  teardown was `stop backend` + container rm, NOT `down -v`, because the
  `pgdata` volume and db container predate this work. No repo files were
  touched by the probe (Dockerfile/override lived in /tmp, since removed).
